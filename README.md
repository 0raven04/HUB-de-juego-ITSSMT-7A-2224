## 📖 Descripción

¡Bienvenido al clásico juego de **Piedra, Papel o Tijera** con inteligencia artificial! Este juego cuenta con una IA que aprende de tus movimientos usando probabilidades bayesianas, haciendo cada partida más desafiante.

## ✨ Características

- 🧠 **IA Inteligente**: Aprende de tus patrones de juego
- 🎨 **Interfaz Atractiva**: Diseño moderno y responsive
- 📊 **Sistema de Puntuación**: Seguimiento de victorias en tiempo real
- ⚔️ **Sistema de Duelos**: Compite en duelos de 3 rondas
- 🎯 **Fácil de Usar**: Interfaz intuitiva y amigable

## 🚀 Cómo Jugar

### 📥 Instalación
1. Descarga el archivo `mi-juego 1.0.0.exe`
2. Haz doble clic para ejecutar el juego
3. **¡Listo para jugar!**

### 🎮 Instrucciones de Juego

1. **Elige tu movimiento**:
   - ✊ **Piedra**: Vence a Tijera
   - ✋ **Papel**: Vence a Piedra  
   - ✌️ **Tijera**: Vence a Papel

2. **Haz clic en "Jugar"** para que la IA realice su movimiento

3. **Observa el resultado**:
   - 🟢 **Victoria**: Ganas la ronda
   - 🔵 **Empate**: Nadie gana
   - 🔴 **Derrota**: IA gana la ronda

4. **Cada 3 rondas** se determina el ganador del duelo
5. Usa **"Reiniciar"** para comenzar un nuevo juego

## 🏆 Reglas del Juego
Piedra 🗿 gana a Tijera ✂️
Papel 📄 gana a Piedra 🗿
Tijera ✂️ gana a Papel 📄
