❌⭕ Juego de Gato (Tic-Tac-Toe)

Una implementación clásica del juego de Gato (Tic-Tac-Toe) desarrollada en Python. Este proyecto fue creado para practicar lógica de programación, algoritmos de inteligencia artificial y diseño de interfaces.

✨ Características

Modo Un Jugador: Juega contra la CPU (implementada con algoritmo de heuristica basada en prioridades).

Reinicio Rápido: Botón para limpiar el tablero sin recargar.

🛠️ Tecnologías Utilizadas

Lenguaje: Python

🚀 Instalación y Ejecución

Sigue estos pasos para correr el proyecto localmente.

Prerrequisitos
* Tener instalado Python.

Pasos
1.  Entrar en la capeta dist
2.  dar clic en el archivo ".exe"
3.  Presionar el boton de descargar
4.  descargar el archivo ejecutable
5.  Ejecutar el juego


🎮 Cómo Jugar

1.  El juego comienza con el jugador **X**.
2.  Haz clic en cualquier casilla vacía para hacer tu movimiento.
3.  El objetivo es alinear 3 símbolos (horizontal, vertical o diagonal).
4.  Si el tablero se llena y nadie gana, es un empate.
